# Aliff Coway Sales Site — V3 CMS

Netlify-ready Coway sales website with a persistent admin CMS.

## CMS

Open `/admin.html` after deployment.

Manage:

- Website name
- WhatsApp number
- Email and tagline
- Products and prices
- Product images
- Blog articles
- Blog cover images
- SEO title/description/keywords
- Published/draft status

The public homepage loads website settings and products from the CMS automatically.

See `NETLIFY-DEPLOY.md` for deployment instructions.
